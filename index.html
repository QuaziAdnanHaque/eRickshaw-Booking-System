Project Abstract

An academic showcase detailing modular architecture, automated calculations, and database configurations.

Online eRickshaw Booking Portal

The eRickshaw project addresses the issue of organizing un-metered urban micro-transports. Built using the Python-based Django framework, it introduces role-based portals for customers and drivers to securely communicate requests, automate pricing schemes, and list ride histories.

By leveraging standard Django abstractions, the codebase is kept secure, easily maintainable, and modular. It features a complete booking flow from ride request creation to driver acceptance and trip completion.

Ride Lifecycle

State transitions managed in the database:

  • Accepted: Claimed by a driver.
  • Completed: Finalized ride.

Product Roadmap

Future iterations and technical expansions planned to transition into a production service.

1. Geolocation & Map APIs

Integrating Google Maps or OpenStreetMap APIs for active routing, pickup dropdown menus, and automated distance coordinates.

2. Real-Time WebSockets

Implementing WebSockets via Django Channels to notify drivers immediately when a booking request is made near them without page reloads.

3. Cashless Payments

Adding Stripe or Razorpay gateway options to process digital transactions securely on ride completions.

4. Rating & Reviews

Allowing mutual reviews and safety ratings between driver and customer profiles after each ride completion.
